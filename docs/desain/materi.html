Model Komputer Von Neumann

Hampir semua komputer modern, termasuk HP di sakumu, bekerja dengan rancangan yang diusulkan John von Neumann pada 1945. Mari telusuri bagaimana data mengalir dari input hingga menjadi output.

Tujuan pembelajaran

  • Menyebutkan komponen utama arsitektur Von Neumann dan fungsinya.
  • Menelusuri alur data Input–Proses–Output di dalam komputer.
  • Membedakan peran unit kendali (CU) dan ALU saat menjalankan instruksi.

Komponen utama

Ciri khas arsitektur Von Neumann: data dan program disimpan bersama di memori. CPU mengambil instruksi satu per satu dari memori, mengerjakannya, lalu mengirim hasilnya ke perangkat output.

CPU Pusat pemrosesan Unit kendali (CU) mengatur urutan kerja, ALU menghitung, register menyimpan data sementara.
RAM Memori utama Menyimpan data dan program yang sedang dipakai.
I/O Perangkat input & output Keyboard dan mouse memasukkan data; monitor dan printer menampilkan hasil.
BUS Jalur data Menghubungkan CPU, memori, dan perangkat input/output.
